# EduProSuite Free Educational Content & Video Autopilot
Autonomous 100% cloud-native daily educational video rendering and multi-channel syndication engine.

## Capabilities
- **Daily Python Video Rendering**: Generates high-retention 9:16 vertical video lessons (AP STEM, Licensed Trades).
- **YouTube Shorts Auto-Publisher**: Resumable OAuth 2.0 direct uploads to YouTube Shorts with SEO tags and descriptions.
- **Multi-Platform Scheduler**: 15 daily automated publishing slots via GitHub Actions.
